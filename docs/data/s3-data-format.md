# S3 Review Data Format

JSON data for ~6,400 Yelp and synthetic restaurant reviews, analyzed by a DistilBERT sentiment model. Includes neural network activations, Factor Analysis pathway scores, and per-word SHAP explanations.

**Base URL**: `https://models-resources.s3.amazonaws.com/neural-pathways/data/v1/`

## File layout

```
neural-pathways/data/v1/
  index.json                       — summary data for all reviews (~7.7 MB)
  activations/{bucket}.json        — 780-dim activation vectors (256 files, ~50 MB total)
  shap/{fa-fit}/{bucket}.json      — per-word SHAP scores (256 files per fit, ~15 MB each)
```

Files are served with `Cache-Control: max-age=3600` and compressed by CloudFront.

## Review IDs and bucketing

Each review is identified by the first 12 hex characters of the SHA-256 hash of its full text (e.g. `a3f7c2d81e09`). The first 2 characters determine which bucket file contains its detail data, so `a3f7c2d81e09` lives in `activations/a3.json` and `shap/test-fa-7/a3.json`.

## Index file

**Path**: `index.json`

Loaded on startup. Contains everything needed for browsing, filtering, and searching reviews.

### Top-level structure

```json
{
  "metadata": {
    "fa_fits": { ... },
    "review_sets": { ... }
  },
  "reviews": [ ... ]
}
```

### `metadata.fa_fits`

Each key is a Factor Analysis fit name like `train-fa-6` (fit on train split, 6 pathways). Contains the full model parameters needed to reproduce pathway scores from raw activations.

```json
{
  "train-fa-6": {
    "source_split": "train",
    "n_pathways": 6,
    "explained_variance_total": 0.902385,
    "explained_variance_per_pathway": [0.855, 0.022, ...],
    "loadings": [[...], ...],
    "noise_variance": [...],
    "scaler_mean": [...],
    "scaler_scale": [...]
  }
}
```

| Field | Description |
|-------|-------------|
| `source_split` | Which review set's activations were used to fit the model |
| `n_pathways` | Number of factors (pathways) extracted |
| `explained_variance_total` | Fraction of total variance captured by all pathways combined |
| `explained_variance_per_pathway` | Fraction of variance per pathway (array of length `n_pathways`) |
| `loadings` | Factor loading matrix, shape `[n_pathways, 780]` — maps activations to pathway scores |
| `noise_variance` | Per-neuron noise variance, length 780 |
| `scaler_mean` | StandardScaler mean per neuron, length 780 |
| `scaler_scale` | StandardScaler scale per neuron, length 780 |
| `pathway_score_min` | Minimum pathway score across all reviews, per pathway (length `n_pathways`) |
| `pathway_score_max` | Maximum pathway score across all reviews, per pathway (length `n_pathways`) |

Current fits: `train-fa-6`, `test-fa-7`, `dev-fa-6`.

### `metadata.review_sets`

```json
{
  "train": { "count": 2699, "description": "Train split of Yelp reviews" },
  "dev": { "count": 300, "description": "Dev split (validation) of Yelp reviews" },
  "test": { "count": 2998, "description": "Test split of Yelp reviews" },
  "synthetic-gpt": { "count": 432, "description": "Synthetic reviews generated by GPT-4o" }
}
```

### `reviews` array

Each entry:

```json
{
  "id": "5223d89cd83e",
  "sources": { "train": [0] },
  "text": "Awesome New York style pizza...",
  "target": 1,
  "target_label": "positive",
  "name": "Benny Pennello's",
  "city": "Charlotte",
  "state": "NC",
  "stars": 4.0,
  "review_stars": 5,
  "categories": "Fast Food, Pizza, Italian, Restaurants",
  "pathway_scores": {
    "train-fa-6": [-0.123, 0.456, 0.789, -0.234, 0.567, -0.890],
    "test-fa-7": [0.234, -0.567, ...],
    "dev-fa-6": [0.345, -0.678, ...]
  },
  "reconstruction_r2": {
    "train-fa-6": 0.8916,
    "test-fa-7": 0.9067,
    "dev-fa-6": 0.907
  },
  "pathway_variance_fractions": {
    "train-fa-6": [0.85, 0.05, 0.04, 0.03, 0.02, 0.01],
    "test-fa-7": [0.80, 0.08, ...],
    "dev-fa-6": [0.82, 0.06, ...]
  },
  "has_shap": ["test-fa-7", "dev-fa-6"]
}
```

| Field | Type | Description |
|-------|------|-------------|
| `id` | string | 12-char hex SHA-256 of review text |
| `sources` | object | Maps review set name to array of indices within that set. A review appearing in multiple sets has multiple keys. |
| `text` | string | Full review text |
| `target` | int or null | Sentiment label: `1` = positive, `0` = negative, `null` = unlabeled |
| `target_label` | string or null | `"positive"`, `"negative"`, or `null` |
| `name` | string or null | Business name (Yelp reviews only) |
| `city` | string or null | Business city |
| `state` | string or null | Business state |
| `stars` | number or null | Business average star rating |
| `review_stars` | int or null | Star rating on this review |
| `categories` | string or null | Comma-separated business categories |
| `pathway_scores` | object | Per-FA-fit array of pathway scores (length = `n_pathways` for that fit) |
| `reconstruction_r2` | object | Per-FA-fit R² measuring how well pathways reconstruct this review's activations |
| `pathway_variance_fractions` | object | Per-FA-fit array showing each pathway's share of the reconstruction variance |
| `has_shap` | string[] or absent | List of FA fit names that have SHAP data for this review. Omitted if the review has no SHAP data. |

Metadata fields (`name`, `city`, `state`, `stars`, `review_stars`, `categories`) are present only for Yelp reviews. Synthetic reviews omit these fields.

## Activation files

**Path**: `activations/{bucket}.json` (e.g. `activations/a3.json`)

Each file contains the raw 780-dimensional neural network activation vectors for the reviews in that bucket. These are the outputs of the DistilBERT model's final hidden layer, before any Factor Analysis transformation.

```json
{
  "reviews": [
    {
      "id": "a3f7c2d81e09",
      "activations": [0.123, -0.456, ...]
    }
  ]
}
```

| Field | Type | Description |
|-------|------|-------------|
| `id` | string | Review ID (matches index) |
| `activations` | number[] | 780-dimensional activation vector |

256 bucket files, ~25 reviews each, ~195 KB per file uncompressed.

## SHAP files

**Path**: `shap/{fa-fit}/{bucket}.json` (e.g. `shap/test-fa-7/a3.json`)

Per-word SHAP values explaining each pathway's score for a review. Not all reviews have SHAP data — currently 2,272 reviews across the `test` and `synthetic-gpt` sets.

```json
{
  "reviews": [
    {
      "id": "a3f7c2d81e09",
      "base_values": [-0.002, 0.015, ...],
      "unmasked_values": [-1.02, 0.45, ...],
      "words": [
        { "word": "[CLS]", "scores": [-0.002, -0.007, -0.010, 0.010, -0.008, 0.035, 0.028] },
        { "word": "great", "scores": [0.12, -0.03, 0.05, 0.01, -0.02, 0.08, 0.04] },
        { "word": "food", "scores": [0.08, 0.01, -0.01, 0.03, 0.00, 0.02, 0.01] }
      ]
    }
  ]
}
```

| Field | Type | Description |
|-------|------|-------------|
| `id` | string | Review ID (matches index) |
| `base_values` | number[] | SHAP base value per pathway (expected score with no words) |
| `unmasked_values` | number[] | Full unmasked prediction per pathway |
| `words` | object[] | Tokenized words with per-pathway SHAP contributions |
| `words[].word` | string | Token text (includes `[CLS]`, `[SEP]`, and subword-joined tokens) |
| `words[].scores` | number[] | SHAP contribution to each pathway (length = `n_pathways` for this fit) |

The SHAP scores are additive: `base_values[p] + sum(word.scores[p] for word in words)` approximates the pathway score for pathway `p`.

Current SHAP fits: `dev-fa-6`, `test-fa-7`. 256 bucket files per fit, ~9 reviews per file.

## Typical access pattern

1. Fetch `index.json` on load. Use it for browsing, filtering, and searching reviews.
2. When drilling into a review, compute its bucket from `id[:2]` and fetch the relevant detail files:
   - `activations/{id[:2]}.json` for raw activation vectors
   - `shap/{fa-fit}/{id[:2]}.json` for word-level SHAP explanations
3. Cache fetched bucket files — other reviews in the same bucket are available immediately.
